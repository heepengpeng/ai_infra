# M5 · Lesson 2:PTQ vs QAT——训练后量化与量化感知训练

> 上一课你学会了"怎么把一个张量量化"。但真实模型有几百个张量,激活值还会随输入变化——**那些 scale 到底怎么定下来的?** 这就是本课的主角:PTQ(训练后量化)靠**校准(calibration)**,QAT(量化感知训练)靠**训练时模拟量化**。你在 MindSpore Lite 喂校准数据那一步,本质就是 PTQ 校准;这一课把它讲透,再讲清什么时候不得不上 QAT。

## 1. 一张图看懂两条路线

量化 scale 的确定有两种哲学:

```
PTQ(Post-Training Quantization,训练后量化):
  已训练好的 FP 模型 ──喂少量校准数据──► 统计激活范围 ──► 算 scale ──► 量化
  ▲ 不动权重,不反向传播。几分钟~几小时搞定。

QAT(Quantization-Aware Training,量化感知训练):
  FP 模型 ──插入"伪量化"节点──► 带着量化误差继续训练 ──► 权重学会适应量化
  ▲ 要重新训练(数据 + 算力 + 时间)。精度最好,成本最高。
```

| | PTQ | QAT |
|---|---|---|
| 是否重新训练 | 否 | 是 |
| 需要数据 | 少量校准集(几百条,无需标签) | 完整训练集(带标签) |
| 成本 | 低(分钟~小时) | 高(GPU 天级) |
| 精度 | 中高,低比特时掉点 | 最高,可逼近 FP |
| 适用比特 | INT8 普遍 OK,INT4 吃力 | INT4/INT2 也能保精度 |
| 大模型现状 | **主流**(GPTQ/AWQ 都是 PTQ) | 少用(LLM 太大,QAT 太贵) |

> **先记住大局**:在 LLM 领域,**PTQ 是绝对主流**——因为模型太大,QAT 的训练成本难以承受。后面 L3/L4 的 GPTQ、AWQ 本质都是"更聪明的 PTQ"。QAT 更多见于 CV 小模型和对精度极致苛刻的场景。你在 MindSpore Lite 做的黑盒量化,基本都属于 PTQ。

## 2. PTQ 的核心:校准(calibration)

### 为什么需要校准?

**权重是静态的**——模型训练完,权重就固定了,直接对权重张量取 min/max 算 scale 即可,不需要数据。

**激活是动态的**——激活值 \(X\) 依赖输入,每条样本都不一样。要量化激活,你得先知道"激活大概落在什么范围",这就需要喂一批有代表性的数据(校准集)跑前向,**统计激活的范围**。这个过程就叫**校准**。

```
校准流程:
  校准集(几百条无标签样本)
        │ 逐条前向
        ▼
  在每个要量化的激活点挂一个"观察器(observer)"
        │ 累积统计量(min/max 或直方图)
        ▼
  根据统计量算出每个激活的 scale / zero-point
```

> **校准集要有代表性**:它必须覆盖真实推理时的数据分布。校准集偏了,算出的范围就偏,量化精度跟着崩。这也是你在 MindSpore Lite 里"喂错校准数据导致掉点"问题的根源。一般几百到上千条即可,不需要标签。

### 校准方法:别傻乎乎用 min/max

最朴素的做法是取激活的绝对 min/max 作为范围。问题在 L1 讲过:**outlier 会把范围撑大,导致正常值精度崩**。所以有更聪明的校准策略:

| 校准方法 | 思路 | 特点 |
|---|---|---|
| **Min-Max** | 直接取最小/最大值 | 简单,但对 outlier 极敏感 |
| **百分位(Percentile)** | 取 99.9% / 99.99% 分位作边界,砍掉极端尾部 | 简单有效,需调分位数 |
| **MSE / L2** | 搜索一个范围,使量化前后的均方误差最小 | 在 clip 误差和 round 误差间自动权衡 |
| **KL 散度(熵校准)** | 选范围使量化后分布与原分布的 KL 散度最小(TensorRT 经典做法) | 保留分布形状,适合激活 |

核心都是在 L1 那个矛盾里找平衡:

> **范围取大 → clip 误差小但 round 误差大;范围取小 → round 误差小但 clip 误差大。** 校准就是自动找这个最优范围。Min-Max 是"范围取到最大"的极端,百分位/MSE/KL 则主动牺牲一点 clip 来换 round 精度。

### 静态量化 vs 动态量化

激活量化还分两种时机:

- **静态量化(static)**:校准阶段就把激活的 scale 定死,推理时直接用。快,但范围是"平均估计",对分布变化大的输入不够准。
- **动态量化(dynamic)**:推理时**实时**对每个输入算激活的 scale。准,但每次都要扫一遍激活算 min/max,有额外开销。

> LLM 里常见的折中是 **权重静态量化 + 激活动态量化**(如 W8A8 的一些实现),或者干脆 **只量化权重、激活保持 FP16**(W4A16,根本不用校准激活)。后者正是 L1 说的"decode 带宽大头是权重"的直接推论。

## 3. 权重 vs 激活:难度天壤之别

这是理解整个 LLM 量化领域的关键一点:

```
权重 W:                         激活 X:
- 静态,训练完就固定             - 动态,随输入变化
- 分布规整(近高斯,以 0 为中心) - 有极端 outlier 通道(Transformer 特有)
- 量化相对容易                   - 量化困难(outlier 难处理)
→ INT4 都能做                    → INT8 都吃力,INT4 几乎不可能
```

Transformer 的激活里存在少数幅度极大的**离群通道(outlier channels)**——某几个特征维度的激活值比其他维度大几十上百倍。这些 outlier:
- 对模型精度很重要(不能直接砍掉);
- 又让激活的范围被撑得极大(per-tensor 量化崩盘)。

> **这就是为什么主流 LLM 量化是 W4A16(只量化权重)**:权重好量化,激活难量化就干脆不量化。而要做 W8A8(激活也量化),就必须专门处理 outlier——这正是 L4 的 SmoothQuant 要解决的问题。先把这个"权重易、激活难"的认知刻进脑子,后面所有算法选型都围绕它。

## 4. QAT:让模型"预习"量化误差

PTQ 是"训练完再量化",模型没机会适应量化噪声。QAT 反其道而行:**在训练时就把量化误差模拟进去**,让权重在训练中主动学习如何抵抗量化损失。

做法是在网络里插入**伪量化节点(fake quantization)**:前向时对权重/激活做一次"量化→反量化",制造出和真实量化一样的误差,但数据类型仍是浮点(方便继续训练)。

```
普通前向:        x ─────────────► W·x
QAT 前向: x ─► [quant→dequant] ─► W'·x   (W' 带有量化误差,训练去适应它)
                    伪量化节点
```

### 关键难题:量化不可导,梯度怎么传?

`round()` 函数的导数几乎处处为 0(阶梯函数),如果照实算梯度,反向传播一到伪量化节点梯度就变 0,**训练完全无法进行**。

```
round(x) 的真实导数:
  导数 ▲
      │   . . . . . .        ← 阶梯之间导数 = 0
      │   <- 几乎处处 0,梯度传不过去
      └──────────────► x
```

### STE:直通估计器(Straight-Through Estimator)

解决办法简单又"耍赖":**前向照常做量化,反向时假装量化函数是恒等函数**(导数 = 1),让梯度"直接穿过"量化节点。

\[
\text{前向: } y = \text{quant}(x), \qquad \text{反向: } \frac{\partial y}{\partial x} \approx 1
\]

```
前向:  x ──► round/quant ──► y       (真量化,产生离散误差)
反向:  grad_x ◄── (×1) ◄── grad_y    (假装导数=1,梯度直通)
```

通常还会加一个**裁剪**:对落在量化范围 \([q_{\min}, q_{\max}]\) 外的值,梯度置 0(因为它们被 clip 了,改它们不影响输出)。这就是带 clip 的 STE。

> **STE 是 QAT 的灵魂**。它在数学上不严格(前向反向用的不是同一个函数),但工程上极其有效——正因为有它,模型才能"带着量化误差"训练,让权重分布自动向"量化友好"的方向移动。直觉:STE 让优化器看到"量化让 loss 变大了",于是去调整权重减小这个损失。

## 5. 怎么选:PTQ 还是 QAT?

一张决策表:

| 场景 | 推荐 | 理由 |
|---|---|---|
| LLM(7B 以上),要 INT8/INT4 | **PTQ**(GPTQ/AWQ) | 模型太大,QAT 训练不起;先进 PTQ 已够好 |
| 小模型(CV/语音),INT8 | PTQ 先试 | 多数能满足,成本低 |
| 小模型,INT8 掉点超预算 | QAT | 有训练资源时能把点补回来 |
| 极低比特(INT4/INT2)且精度苛刻 | QAT | PTQ 在极低比特下误差太大 |
| 没有训练数据/算力 | PTQ | QAT 根本做不了 |

实践工作流(强烈推荐):

> **永远先试 PTQ**(便宜、快),测精度。如果掉点在预算内,收工。掉点超预算,再考虑:① 换更好的 PTQ 算法(GPTQ/AWQ)② 提高粒度(per-group)③ 混合精度(敏感层保留高精度)④ 实在不行才上 QAT。对 LLM,90% 的情况停在前三步,根本走不到 QAT。

4. 一个 13B LLM,你只有 1 张 4090 和几百条无标签文本,要把它量化到 INT4 部署。你会用 PTQ 还是 QAT?为什么?
5. 为什么说"W4A16 根本不用校准激活"?

<details>
<summary>参考答案(想完再看)</summary>

1. 权重训练完是**静态**的,直接对权重张量统计范围即可;激活是**动态**的,依赖输入,必须喂代表性数据跑前向才能观测到它的真实范围。

2. 当激活/权重里有 outlier 时,Min-Max 会把范围撑到 outlier 那么大,导致正常值被挤进极少的整数格,精度崩。百分位校准砍掉极端尾部(如只保留 99.9%),用很小的 clip 误差换来正常值大幅减小的 round 误差。

3. round 的导数几乎处处为 0,梯度传到伪量化节点就归零,反向传播断链,**训练无法进行**(权重不更新)。STE 假装导数为 1 让梯度直通,才使训练可行。

4. **PTQ**(且用 GPTQ/AWQ)。理由:① 没有标签和训练算力,QAT 做不了;② 几百条无标签数据正好够 PTQ 校准;③ 单卡 4090 跑 GPTQ 量化 13B 几小时可完成,而 QAT 13B 需要多卡训练多天。

5. W4A16 只量化权重、激活保持 FP16。激活不量化就不需要确定激活的 scale,也就不需要喂校准数据统计激活范围。权重是静态的,直接算范围即可。校准只在"要量化激活"时才必须。

## 小结

- **PTQ**:训练后用少量校准数据定 scale,不重训,成本低,是 **LLM 主流**;**QAT**:训练时插伪量化节点让权重适应量化,精度最高但成本高,LLM 少用。
- **校准**是 PTQ 的核心:用代表性数据统计激活范围。别用 Min-Max(怕 outlier),用**百分位/MSE/KL**在 clip 与 round 误差间找平衡。
- **权重易量化、激活难量化**(Transformer 激活有 outlier 通道),这是 W4A16 流行、W8A8 需特殊处理的根本原因。
- **QAT 的灵魂是 STE**:前向真量化、反向假装导数为 1,让梯度直通,模型才能带量化误差训练。
- 选型铁律:**先试 PTQ**,掉点超预算再升级算法/粒度/混合精度,最后才考虑 QAT。
