# M5 · Lesson 4:AWQ 与 SmoothQuant——和 outlier 正面交锋

> GPTQ 用"误差补偿"对付量化损失。本课的两个算法换了完全不同的思路,都瞄准 L2 反复提到的那个老对手——**激活里的离群通道(outlier)**。AWQ 说:"既然有的权重特别重要,那就**按激活幅度去保护它们**";SmoothQuant 说:"激活难量化、权重好量化,那我就**把难度从激活搬一部分到权重身上**,让两边都不那么难"。理解这两招,你就能看懂 W4A16 和 W8A8 这两条主流路线为什么这么分。

## 1. 共同的敌人:outlier 通道

先把 L2 的结论拎出来当背景。Transformer 的激活 \(X\) 里,**少数几个通道(特征维度)的幅度远大于其他通道**(大几十上百倍),且这些大通道对模型精度很重要。

```
激活 X 的各通道幅度(示意):
通道:  c0   c1   c2   c3   c4   c5  ...
幅度:  ▏    ▏   ████████  ▏    ▏   ▏      ← c2 是 outlier 通道
       └ 正常通道 ┘  ↑大几十倍
```

这给量化出了两道难题:
- 直接量化激活(W8A8 的 A8):outlier 把范围撑大,正常通道精度崩。
- 量化权重(W4A16 的 W4):和 outlier 激活相乘的那些权重列特别重要,量化它们误差会被放大。

AWQ 和 SmoothQuant 是对付这个敌人的两种不同战术。

---

## 2. AWQ:激活感知的权重量化(W4A16)

AWQ 全称 **Activation-aware Weight Quantization**。它只量化权重(W4A16,和 GPTQ 同赛道),核心来自一个被实验证实的观察:

> **不是所有权重一样重要。少数(约 0.1%~1%)"显著权重(salient weights)"对模型输出影响极大,保护好它们,量化精度就能大幅回升。** 而判断哪些权重显著,看的不是权重本身大小,而是**它对应的输入激活幅度**——激活大的那些通道所连的权重,就是显著权重。

这正是"激活感知(activation-aware)"的含义:**用激活的统计信息来判断权重的重要性**。

### 怎么保护?不是混合精度,而是缩放

最直接的保护办法是:把那 1% 显著权重保留 FP16,其余量化 INT4(混合精度)。但 AWQ **没这么做**,因为混合精度让权重矩阵有两种数据类型,硬件实现别扭、kernel 难写、速度受损。

AWQ 的巧办法:**per-channel 缩放(scaling)**。对显著的输入通道 \(j\),把权重列乘上一个放大因子 \(s_j > 1\),同时把对应激活除以 \(s_j\) 保持数学等价:

\[
Y = X W = \big( X \cdot \text{diag}(s)^{-1} \big)\big(\text{diag}(s) \cdot W\big)
\]

为什么放大能保护?回忆 L1:量化误差 ≈ \(s_{\text{quant}}/2\) 的舍入噪声,**这个噪声大小和权重本身的量级无关**(由量化 scale 决定)。所以把显著权重放大,它相对量化噪声的"信噪比"就提高了——同样的噪声,叠加在大值上影响的相对误差更小。

```
保护前:显著权重  w=0.05,量化噪声 ±0.01 → 相对误差 20%
保护后:放大 4×   w=0.20,量化噪声 ±0.01 → 相对误差 5%  ✓
        (激活同步 ÷4 保持 Y 不变)
```

> **AWQ 一句话**:用激活幅度找出显著权重,通过 per-channel 缩放(放大显著权重 / 同步缩小对应激活)提高它们的量化信噪比,从而在纯 INT4(无混合精度)下保住精度。缩放因子 \(s\) 通过一个小搜索(网格搜索使量化误差最小)确定。

AWQ 不需要反向传播、不需要 Hessian 求逆,**比 GPTQ 更轻量、量化更快**,且因为只是缩放变换、对校准数据不那么敏感,泛化性好。

## 3. SmoothQuant:把难度从激活迁移到权重(W8A8)

SmoothQuant 的目标和 AWQ 不同:它要做 **W8A8**(权重和激活**都**量化成 INT8),目的是用上 INT8 的整数矩阵乘单元(吞吐高,prefill/计算受限场景受益大)。

但 W8A8 的拦路虎正是激活 outlier。SmoothQuant 的洞察非常漂亮:

> **激活难量化(有 outlier),权重好量化(分布平滑)。那为什么要让激活一个人扛所有难度?把一部分难度"迁移"给权重,让两边都变得中等难度,整体就好量化了。**

### 数学:一个等价的"难度搬运"变换

和 AWQ 同款的等价变换(这不是巧合,两者数学骨架相通):

\[
Y = X W = \big( X \cdot \text{diag}(s)^{-1} \big)\big(\text{diag}(s) \cdot W\big) = \widehat X \, \widehat W
\]

对每个通道 \(j\),激活除以 \(s_j\)(**变平滑、好量化**),权重乘以 \(s_j\)(**变陡峭一点、难一点**)。关键是怎么选 \(s_j\),让两边"难度均衡"。SmoothQuant 给出一个带强度旋钮 \(\alpha\) 的公式:

\[
s_j = \frac{\big(\max_i |X_{ij}|\big)^{\alpha}}{\big(\max_i |W_{ij}|\big)^{1-\alpha}}
\]

- \(\alpha\) 是**迁移强度**(migration strength),通常取 0.5。
- \(\alpha\) 越大,迁移给权重的难度越多(激活更平滑、权重更陡)。
- \(\alpha=0.5\) 时,激活和权重的量化难度大致**对半分**。

```
迁移前:                          迁移后(α=0.5):
激活 X: ▏▏████████▏▏ (难,outlier) 激活 X̂: ▏▏███▏▏      (中等,可 INT8)
权重 W: ▏▏▏▏▏▏▏▏    (易,平滑)     权重 Ŵ: ▏▏███▏▏      (中等,可 INT8)
        ↑难度全在激活                      ↑难度被对半分摊
```

> **SmoothQuant 一句话**:激活的量化难度(outlier)通过一个逐通道的等价缩放,被"搬运"一部分到权重上,使激活和权重都变成中等难度,从而 W8A8 可行。\(\alpha\) 控制搬多少。这个缩放可以**离线**算好并融进前一层(如 LayerNorm),推理时零额外开销。

## 4. W4A16 vs W8A8:两条路线的分工

AWQ/GPTQ 是 W4A16,SmoothQuant 是 W8A8,它们**不是竞品,而是面向不同场景**:

| | W4A16(AWQ/GPTQ) | W8A8(SmoothQuant) |
|---|---|---|
| 量化对象 | 仅权重 INT4 | 权重 + 激活都 INT8 |
| 主要收益 | 省**带宽**(decode 提速)+ 省显存 | 用 **INT8 算力**(吞吐/计算受限场景) |
| 最佳场景 | **小 batch、decode 为主**(聊天、单请求低延迟) | **大 batch、prefill 重**(离线批处理、高并发吞吐) |
| 为什么 | decode 带宽受限,权重是大头,激活留 FP16 避 outlier | 大 batch/prefill 计算受限,INT8 矩阵乘吞吐翻倍 |
| outlier 处理 | AWQ:缩放保护显著权重 | SmoothQuant:难度迁移到权重 |

呼应 L1 的 roofline:
- **decode 带宽受限** → 减字节最有效 → **W4A16**(权重 bit 砍到 1/4)。
- **prefill / 大 batch 计算受限** → 提算力最有效 → **W8A8**(吃 INT8 Tensor Core 的高吞吐)。

> **这是本课最该带走的判断力**:看你的负载在 roofline 的哪一侧。**带宽受限选 W4A16,算力受限选 W8A8。** 很多生产系统两者并用——甚至 W4A8(权重 INT4 省带宽 + 激活 INT8 用算力)这种组合也在兴起。

## 5. 三大算法横向对照

| 算法 | 路线 | 核心武器 | 是否需 Hessian | 量化速度 | 典型用途 |
|---|---|---|---|---|---|
| **GPTQ** | W4A16 | 逐列误差补偿(二阶) | 是(\(XX^\top\) 求逆) | 中 | INT4 权重,精度优先 |
| **AWQ** | W4A16 | 激活感知缩放保护显著权重 | 否 | 快 | INT4 权重,部署友好/泛化好 |
| **SmoothQuant** | W8A8 | 难度从激活迁移到权重 | 否 | 快 | INT8 全量化,吞吐场景 |

实践建议:

> W4A16 想要部署,**AWQ 和 GPTQ 都试**,选 PPL/下游精度更好的那个(经验上两者互有胜负,AWQ 量化更快、对校准集更鲁棒)。要做 W8A8 吞吐优化,上 **SmoothQuant**(常和 GPTQ/AWQ 不冲突,可叠加思路)。

## 练习题

1. AWQ 判断"权重是否重要"看的是权重大小还是激活大小?为什么?
2. AWQ 为什么用"per-channel 缩放"而不是"把重要权重保留 FP16"来保护?
3. SmoothQuant 的等价变换 \(X W = (X\,\text{diag}(s)^{-1})(\text{diag}(s)\,W)\) 为什么能保持输出不变?
4. SmoothQuant 的 \(\alpha\) 取 0 和取 1 分别意味着什么极端?
5. 你要部署一个聊天机器人(单用户、低延迟、decode 为主)和一个离线文档批处理(大 batch、吞吐为主),分别选 W4A16 还是 W8A8?为什么?

<details>
<summary>参考答案(想完再看)</summary>

1. 看**激活大小**。因为输出 \(Y=WX\),一个权重对输出的贡献 = 权重 × 它乘的激活。激活大的通道,即使权重不大,对输出影响也大;量化这些"连着大激活"的权重列误差会被放大,所以它们才是"显著权重"。这就是"激活感知"。

2. 因为保留 FP16 会让权重矩阵混入两种数据类型,硬件 kernel 难写、访存不规整、速度受损。per-channel 缩放保持权重全是 INT4(类型统一、kernel 简单),只是改变了数值分布以提高显著权重的量化信噪比,等价变换不改输出。

3. 因为 \(\text{diag}(s)^{-1}\) 和 \(\text{diag}(s)\) 相乘等于单位阵:\((X\,\text{diag}(s)^{-1})(\text{diag}(s)\,W) = X\,(\text{diag}(s)^{-1}\text{diag}(s))\,W = XW\)。逐通道地"激活除以 s、权重乘以 s",数学上完全等价,只是改变了量化前的数值分布。

4. \(\alpha=0\):\(s_j = 1/\max|W_{ij}|^{1}\) 形式,几乎不从激活迁移难度(激活仍难量化);\(\alpha=1\):\(s_j=\max|X_{ij}|\),把激活的难度几乎全推给权重(激活变很平滑但权重可能变得很难)。0.5 是对半分的平衡点。

5. 聊天机器人:**W4A16**——单用户 decode 为主、带宽受限,量化权重直接加速 decode、降延迟。离线批处理:**W8A8**——大 batch 计算受限,INT8 矩阵乘吞吐翻倍,SmoothQuant 让激活也能 INT8。判断依据就是负载在 roofline 的带宽侧还是算力侧。

</details>

## 小结

- AWQ/SmoothQuant 都瞄准**激活 outlier**,但战术不同。
- **AWQ(W4A16)**:激活感知地识别显著权重(看激活幅度),用 **per-channel 缩放**放大显著权重提高量化信噪比,纯 INT4 无混合精度,轻量、泛化好。
- **SmoothQuant(W8A8)**:用等价缩放把激活的量化**难度迁移**给权重(\(\alpha\) 控强度),让两边都中等难度,从而 INT8 全量化可行,缩放可离线融入前层零开销。
- **路线分工**:decode/带宽受限选 **W4A16**(GPTQ/AWQ),prefill/大 batch/算力受限选 **W8A8**(SmoothQuant);判断标准是 roofline 哪一侧。
- 三大算法:GPTQ(二阶补偿)、AWQ(缩放保护)、SmoothQuant(难度迁移),按场景与精度需求选用。
